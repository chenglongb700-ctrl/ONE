## 明晚怎样描述一个功能

1. **场景**：什么时候、在什么情况下会用？现在没有它，哪里不方便？
2. **想要的结果**：用完之后你得到什么？
3. **要记哪些信息**：每条记录有哪些内容？比如日期、时长、分类、备注。
4. **放在哪里**：单独一个页面、首页一张卡片，还是某个页面里的按钮？
5. **必须有 / 最好有 / 不需要**：先做最小可用的版本。
6. **参考**：用过的哪个 App 有类似功能，喜欢或讨厌它哪一点。

没想好的地方写“不确定”就行。
